沿着这条顺序观察

先拖动 τ 制备压缩态，再点“对齐长轴到 z”，最后拖动 φ。椭球的形状与大小保持不变，中心沿圆弧移动，椭球朝向也一起旋转；固定 y–z 平面的投影则可以变宽或变窄。

灰色虚线：φ = 0 的参考态与中心圆轨道。橙色线：从 0 到当前 φ 的中心路径。浅色轮廓：沿途的椭球。椭球只表示均值与协方差，并非完整量子态概率分布。

公式与模型约定
Jα = ½∑ⱼσα⁽ʲ⁾，J = N/2；|ψs⟩ = Rx(α) exp(−iτJz²)|+⟩⊗N；|ψφ⟩ = exp(−iφJz)|ψs⟩。

τ 是已知的制备时间，α 是已知的对齐角；φ 是随后编码、需要估计的相位。

m = (N/2) cosN−1τ，⟨Jy⟩OAT = ⟨Jz⟩OAT = 0
Vx = N/4 + N(N−1)[1 + cosN−2(2τ)]/8 − N²cos2N−2τ/4
Vy = N/4 + N(N−1)[1 − cosN−2(2τ)]/8，Vz = N/4
C = N(N−1) sinτ cosN−2τ/4；V± = [Vy + Vz ± √((Vy − Vz)² + 4C²)]/2

对齐角 α = ½ atan2(2C, Vz − Vy)，使制备后的协方差为 diag(Vx, V−, V+)。τ = 0 时 Vx = 0，三维椭球自然退化为圆盘。

中心：⟨J⟩φ = m(cosφ, sinφ, 0)
协方差：Σφ = Rz(φ) Σs Rz(φ)T；三个主轴方差不变。
完成对齐后：Varφ(Jy) = Vx sin²φ + V− cos²φ，Varφ(Jz) = V+
ξR² = NV− / m²；FQ = 4V+ ≥ N/ξR²。

ξR²/(νN) 是 φ = 0 处线性均值估计的方差，并非一般的最优量子精度。较长制备时间的非高斯结构不能由协方差椭球完整表达。
