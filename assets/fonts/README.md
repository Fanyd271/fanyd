# Bundled fonts

- STIX Two Text and Source Sans 3 are Latin webfonts from Google Fonts. Their original SIL Open Font Licenses are retained alongside the files.
- `wenkai-common.woff2` is derived from [LXGW WenKai Lite Regular](https://github.com/lxgw/LxgwWenKai-Lite), under the SIL Open Font License in `WenKai-OFL.txt`. The modified font family is named `Fanyd WenKai Web`; original copyright and license metadata are retained.

The Chinese subset contains GB2312 CJK characters, Chinese characters used by the homepage and resource pages at creation, and common punctuation. Characters outside the subset use the system Kai/Song fallback. It is delivered only as a webfont. No proprietary system font is redistributed.
